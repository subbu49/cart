## 🔧 If Something Goes Wrong

### Dev server won't start?
```

2. Run: cd /d c:\Users\sumanth.nerella\ecart\multimart_frontend
3. Run: npm install
4. Run: npm run dev
```

### Different port?
```
npm run dev -- --port 3001
```

### Clear cache?
```
npm cache clean --force
npm install
npm run dev
```
